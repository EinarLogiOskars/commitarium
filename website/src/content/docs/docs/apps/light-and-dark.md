This page explains how your apps look in light and dark, and how to change it.

## New apps get both

Unless you ask for a particular look, an app with a screen gets a **light** and a **dark** theme, and a **System / Light / Dark** setting of its own that it remembers. **System** follows your computer's appearance.

Mayka lists this among the things she assumed for the app, so you can say otherwise before it is built.

## It starts from Commitarium's theme

When Commitarium opens an app in its window, it tells the app which theme Commitarium is showing. The app starts in the same one, so a dark Commitarium opens a dark app. After that, the app's own setting decides, and changing Commitarium's theme later does not reload the app.

A [deployed app](/docs/online/deploying/) has no Commitarium around it, so it starts from the visitor's device theme instead.

## Commitarium's own theme

Commitarium itself has an **Appearance** setting in **Settings > General**: **System**, **Light** or **Dark**.

## Changing an app's look

Ask for it like any other change: "Make it dark only", "Use green as the main colour", "Make the rows more compact". See [Asking for changes](/docs/apps/asking-for-changes/).
