This page shows you how to turn on Developer mode, and what changes when you do.

:::note
A short video for this section is coming.
:::

Without Developer mode, Commitarium is just your apps. With it, you see the workshop behind them: projects, chats with Mayka, work orders, the agents at work, and the code's history.

You don't need it to make or change apps. Turn it on if you write code yourself, want to bring in a project you already have, or are curious how your apps are made.

## Turn it on

1. Open **Settings**.
2. In **General**, tick **Developer mode** ("Show projects, work orders, and the audit viewer").

<Screenshot id="settings-general" alt="Settings, General section, with the Developer mode switch and the Appearance choice" />

## What you get

- **Projects and chats** in a sidebar on the left. Every app is a project. **All** beside Projects lists them all, with **New project** and **Import project**.
- **A chat with Mayka** in the centre of each project, with **cards** beside it for the plan, work orders, agents, preview and sync. See [The chat and the cards](/docs/developer-mode/the-chat-and-cards/).
- **The audit viewer**, a read-only window into Commitarium's private Git server. See [The audit viewer](/docs/server-care/audit-viewer/).

## A project or an app

A project you make in Developer mode is not an app until you say so. In the project's settings, the **App** section uses it as an app: it then shows in the Apps area and opens in its own window. You can switch it back at any time.

## New project

**New project** asks for a name and, if you like, what you are building. Mayka writes the vision from it and recommends a stack. To think it through first, plan it with Mayka beside a live plan, then build it: see [Plan mode](/docs/developer-mode/plan-mode/).
