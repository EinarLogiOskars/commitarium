This page explains what Mayka tells you about a project you just imported, and what you can do with it.

## What she looks at

Right after an import, Mayka reads the project by herself and writes to you in its chat. You don't need to ask, or even keep the window open. Her first look covers:

- **what the app is**, and how the code is laid out;
- **the stack**: whether the stack Commitarium detected matches the code. If not, she proposes the right one;
- **what could come next**, as a numbered list of work she could do;
- **her view** of the project;
- **how the project is set up**, in plain words: whether it stops at each phase, how it merges, the validation checks, review rounds and failed runs. All of it can be changed in [Project settings](/docs/developer-mode/project-settings/);
- **how she works** in the project.

## Act on it

Ask her to do any item on the list, by number or in your own words: "Do number 2." It becomes a work order.

## The Build for me card

An imported project starts in **Assists me**: Mayka suggests, and you approve. Under her first look, a card offers:

- **Build for me**, which switches the project to [Builds everything](/docs/apps/assists-or-builds/), so Mayka takes it from there;
- **Not now**, which hides the card for this project.
