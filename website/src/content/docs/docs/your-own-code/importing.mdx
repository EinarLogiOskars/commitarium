This page shows you how to bring existing code into Commitarium, so Mayka and your agents can work on it.

:::note
A short video for this section is coming.
:::

Importing needs [Developer mode](/docs/developer-mode/turning-it-on/). Open **All** beside Projects in the sidebar, then **Import project**.

Commitarium works on its own copy. Your original stays as it is, and only changes when you [sync](/docs/your-own-code/syncing/).

## From a folder on this computer

1. Choose **Choose folder…** and pick the project's folder.
2. Commitarium says whether it is a **Git repository** or a **Plain folder**.
   - A Git repository needs at least one commit, and no uncommitted changes. Commit them first, so the import captures your work.
   - A plain folder is copied as it is, as a first commit. Your `.gitignore` is respected.
3. Check the name and the default branch.
4. Under **Project defaults**, you can set the autonomy, merge and recovery policies. You can change most of them later in [Project settings](/docs/developer-mode/project-settings/).
5. Choose **Import project**.

Commitarium then looks for the project's toolchain, the languages and versions it uses. **Use detected stack** accepts it, or you can choose it yourself.

## By address, on a server

A server can't see the folders on your computer. When you are [connected to a server](/docs/servers/switching/), Import asks for the repository instead:

1. **Repository address**: its https address, such as `https://github.com/you/app.git`.
2. **Name**: filled in from the address.
3. **Access token**: a token from your Git host that can read and push to the repository. A public repository imports without one, but can then only pull.

Commitarium copies the repository onto the server and links the project to it, so you can pull new commits and push back. See [the linked repository](/docs/your-own-code/syncing/#on-a-server-a-linked-repository).

:::tip
On GitHub, a fine-grained token limited to this one repository, with **Contents: read and write**, is enough.
:::

## What happens next

As soon as the import finishes, Mayka takes a [first look](/docs/your-own-code/first-look/) at the project.
