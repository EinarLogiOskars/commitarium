This page shows you how updates work, for the app and for your servers.

## The app

Commitarium tells you when a new version is out, and updates itself when you agree. **Settings > About** shows the version you have.

## Your server

Your app tells you when your server has an update. You choose when to install it, in **Settings > Server**, with **Update server**. It waits until running work orders finish.

<Screenshot id="settings-server" alt="Settings, Server section: the connected server, its update, devices and domain" />

The app and the server should be on the same version. If one is too old for the other, Settings says which one to update.

## If an update goes wrong

Run the install line again on the server. It keeps your data:

```bash
curl -fsSL https://github.com/EinarLogiOskars/commitarium/releases/latest/download/install-host.sh | sudo sh
```

## Installing a given release

To install a particular release instead of the latest, such as a release candidate, take the install line from that release and name its version:

```bash
curl -fsSL https://github.com/EinarLogiOskars/commitarium/releases/download/v0.11.0-rc.1/install-host.sh | sudo sh -s -- --version 0.11.0-rc.1
```

A server on a release candidate is offered the full release once it is out.
