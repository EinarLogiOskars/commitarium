Commitarium is two things in one app, and you can use either or both:

- **Apps, for anyone.** Describe an app in a sentence. Mayka, the assistant, plans it, has coding agents build it, and opens it on your computer. Ask for changes the same way. No code needed.
- **A workshop, for developers.** Bring your own repository. Mayka turns what you want into planned work orders; a lead agent builds each one and a reviewer agent, ideally from another provider, challenges every plan and every change before it merges. Every change is a pull request in a private Git server on your machine, and you decide how much runs on its own.
